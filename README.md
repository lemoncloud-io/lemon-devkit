# lemon-devkit

local develop kit for [lemon-core](https://github.com/lemoncloud-io/lemon-core)

## Usage

- required to install seperately `lemon-core` in advance.

```sh
# STEP.1 install `lemon-devkit`
npm i --save-dev lemon-devkit
```
